시작 전에 준비할 것

  • Windows PC와 Steam
  • Steam 계정에 등록되고 PC에 설치된 Project Zomboid
  • 서버 운영자에게 직접 받은 플레이어 ZIP
  • 서버 운영자가 별도로 알려 준 공용 서버 비밀번호
현재는 베타 기간입니다. 정식 시작 때 캐릭터와 월드가 초기화될 수 있습니다. 중요한 진행은 운영자의 정식 시작 공지 이후에 이어가세요.

처음 접속하는 방법

  1. 받은 ZIP의 압축을 전부 풉니다.
    ZIP을 우클릭하고 압축 풀기 또는 모두 추출을 선택하세요. 압축 파일 안에서 바로 실행하지 마세요.
  2. Steam에서 Project Zomboid를 최신 Stable로 업데이트합니다.
    게임 메인 화면에서 버전이 42.21.0인지 확인하세요. 예전 ZIP의 DOWNGRADE-CLIENT-TO-42.20.4.cmd는 실행하지 마세요.
  3. JOIN-SERVER.cmd를 더블클릭합니다.
    동봉된 서버 전용 탈출 모드를 자동 설치한 뒤, 처음 한 번은 내 PC에서 켜져 있는 모드와 서버 모드 목록을 비교합니다.
  4. 서버에 없는 모드가 발견되면 Y 또는 N을 선택합니다.
    대부분의 플레이어에게는 Y를 권장합니다. 아래 설명을 먼저 읽어보세요.
  5. Steam과 Project Zomboid가 열릴 때까지 기다립니다.
    첫 접속은 Workshop 모드 다운로드 때문에 시간이 걸릴 수 있습니다. 다운로드 중에는 창을 강제로 닫지 마세요.
  6. 게임 화면에서 로그인 정보를 입력합니다.
    공용 서버 비밀번호는 운영자에게 받은 값을 사용하고, 개인 계정 이름과 개인 계정 비밀번호는 본인이 새로 만듭니다.

모드 정리 질문에서 무엇을 선택하나요?

Y — 정리하기 (권장)

기존 전역 모드 목록을 날짜가 붙은 파일로 안전하게 백업한 뒤 잠시 비활성화합니다.

구독한 모드, 게임 파일, 세이브는 삭제하지 않습니다. 서버에 필요한 모드는 접속하면서 자동으로 불러옵니다.

N — 그대로 두기

내 모드 목록을 바꾸지 않고 접속합니다.

서버에 없는 모드가 켜져 있으면 File doesn't exist on the server 또는 체크섬 오류로 접속이 끊길 수 있습니다.

선택은 같은 서버 모드 목록에서 처음 한 번만 묻습니다. 다시 확인하려면 CHECK-CLIENT-MODS.cmd를 실행하세요.

서버에 적용된 모드

현재 서버 설정에는 Workshop 항목 63개, 실제 모드 모듈 68개가 들어 있습니다. 신규 차량 해체·정비 모드 2개도 설치와 서버 부팅을 통과했으며, 실제 게임 내 기능 확인은 남아 있습니다. 전기 확장과 Infinite Repairs Workshop에는 각각 모듈 두 개, Spawn Table Fix Workshop에는 모듈 세 개가 들어 있고 서버 전용 탈출 모드 하나는 이 ZIP으로 배포하므로 숫자가 서로 다른 것이 정상입니다.

차량 트렁크 사용은 기본 게임 기능입니다. 별도의 트렁크 모드가 없어도 차량 뒤쪽에서 트렁크를 열어 물건을 넣고 뺄 수 있습니다.
쓰레기통에 넣은 물건은 모두 삭제 버튼으로 영구 삭제할 수 있습니다. 일반 보관함에는 이 버튼이 없으며, 삭제한 물건은 복구할 수 없으니 누르기 전에 꼭 확인하세요.
More Traits와 Common Sense는 이 서버에 적용되어 있지 않습니다. 모드 목록에서 두 이름이 보인다면 개인 모드가 켜진 것이므로 게임을 종료하고 CHECK-CLIENT-MODS.cmd를 실행한 뒤 Y를 선택하세요.

일부 모드 화면에는 아직 영문이 남을 수 있습니다. 이상한 문구나 번역 키가 그대로 보이면 화면을 캡처해 운영자에게 보내주세요.

사망 후 은신처에서 부활하기

  1. 건물 안에서 은신처를 설정합니다. 이미 다른 사람이 만든 은신처라면 소유자에게 구성원으로 추가해 달라고 요청하세요.
  2. 은신처 관리 화면에서 내 이름이 구성원 목록에 있는지 확인하고 은신처에서 부활 옵션을 선택합니다.
  3. 사망한 뒤 같은 멀티플레이 계정으로 새 캐릭터를 만들면 소속 은신처에서 시작합니다.
이 설정은 사망 후 새 캐릭터에게 적용됩니다. 처음 접속한 캐릭터의 시작 위치나 평소 재접속 위치를 바꾸지는 않습니다.

비밀번호가 두 종류인가요?

공용 서버 비밀번호운영자가 모든 참가자에게 알려 주는 접속용 비밀번호입니다.
내 계정 이름서버 안에서 사용할 본인 이름입니다.
내 계정 비밀번호본인 캐릭터를 보호하는 개인 비밀번호입니다. 다른 사람과 공유하지 마세요.
플레이어 ZIP에는 서버 비밀번호나 DuckDNS token이 들어 있지 않습니다. 비밀번호를 요구하는 수상한 파일이나 링크는 실행하지 말고 운영자에게 확인하세요.

두 번째 접속부터

압축을 풀어 둔 폴더에서 JOIN-SERVER.cmd만 더블클릭하면 됩니다. 서버 주소가 바뀌더라도 DDNS가 자동으로 연결하므로 보통 새 주소를 입력할 필요가 없습니다.

운영자가 새 플레이어 ZIP을 보내면 기존 ZIP 위에 덮어쓰지 말고 새 폴더에 풀어 사용하세요. 실행할 때 새 탈출 모드가 자동 갱신되며 이전 버전은 안전하게 백업됩니다.

내 싱글플레이 모드를 다시 사용하려면

  1. Project Zomboid를 완전히 종료합니다.
  2. RESTORE-CLIENT-MODS.cmd를 더블클릭합니다.
  3. 백업해 둔 기존 전역 모드 목록이 복구됩니다.
  4. 다시 이 서버에 접속할 때는 CHECK-CLIENT-MODS.cmd를 실행하고 Y를 선택하세요.

폴더 안 파일 설명

OPEN-MANUAL.cmd지금 보고 있는 안내서를 엽니다.
JOIN-SERVER.cmd모드 확인 후 서버 접속을 시작합니다.
CHECK-CLIENT-MODS.cmd클라이언트 모드를 다시 비교하고 정리 여부를 선택합니다.
RESTORE-CLIENT-MODS.cmd정리 전에 사용하던 전역 모드 목록을 복구합니다.
RESET-SERVER-ADDRESS.cmd운영자가 주소를 바꾸라고 안내했을 때만 사용합니다.
local-mods서버 전용 Knox Escape Quest 모드입니다. 런처가 자동 설치하므로 삭제하거나 직접 수정하지 마세요.

나머지 PS1·JSON 파일은 런처 동작에 필요합니다. 내용을 수정하거나 삭제하지 마세요.

문제가 생겼을 때

File doesn't exist on the server / 체크섬 오류

게임을 완전히 종료하고 CHECK-CLIENT-MODS.cmd를 실행한 뒤 Y를 선택하세요. 다시 접속해도 같으면 Steam과 게임을 종료했다가 다시 실행하세요.

모드 다운로드가 끝나지 않음

Steam의 다운로드 화면을 확인하세요. 다운로드가 멈췄다면 Steam을 재시작하고 다시 접속합니다. 저장 공간도 확인하세요.

서버가 응답하지 않음

운영자에게 서버가 켜져 있는지 먼저 물어보세요. 혼자 네트워크 설정이나 Windows 방화벽을 바꾸지 마세요.

검은 창에 빨간 오류가 표시됨

창을 닫기 전에 오류 화면을 캡처해 운영자에게 보내세요. 비밀번호나 token이 보이면 가리고 보내세요.

Windows가 실행을 경고함

운영자에게 직접 받은 ZIP인지 확인하세요. 출처가 확실하지 않으면 실행하지 마세요. 직접 받은 파일이 맞다면 경고 화면의 파일 이름이 이 안내서의 목록과 같은지 확인한 후 진행합니다.

운영자에게 문의할 때 보내면 좋은 정보

  • 오류 화면 전체 캡처
  • 어느 파일을 눌렀는지
  • 모드 정리 질문에서 Y 또는 N 중 무엇을 선택했는지
  • 처음 접속인지, 이전에는 접속됐는지

계정 비밀번호와 DuckDNS token은 보내지 마세요.
