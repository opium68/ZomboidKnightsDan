# 2026-10-24 운영 설치본 배포

`0.1.0-20261024.1`을 2026-10-25 공개하고 자동 업데이트를 전환했다. 운영 자체 모드와 같은 파일을 참가자에게 배포하며, 공개 다운로드본의 격리 서버 검증을 완료했다.

- 사냥 의뢰 후보를 멀드로우 Dixie Highway 한 곳에서 7개 도시 16곳으로 확대한다. 기존 의뢰와 현재 의뢰판은 유지하며, 새 의뢰판 생성부터 확대된 도시를 선택한다.

- 악기 11종의 학습·악보 읽기·디버그 학습 직후 곡 목록 저장을 보강하고, 연주 완료·중단 때 이미 알고 있던 곡을 보존한다. 이전에 잃은 곡을 자동으로 지급하지 않는다.

검증: 설치된 PZLinux 원본 Lua를 실제 Kahlua에서 실행한 사냥 위치 16곳 선택·의뢰 생성 검사 통과. 16곳의 현재 맵 자산 존재 확인. 사냥 생성·복구 회귀 통과(월드 객체는 대역). 음악 11종 원본 학습·디버그·악보 읽기 및 목록 교체 회귀, 확률 보정 병행 검사 통과. P19A 네 좌석 네이티브 스크립트 병합 검사 통과.

PowerShell 5.1·7에서 서명 설치·재설치 생략·실패 후 복구 검사 통과. 공개 HTTP에서 다시 받은 서명·ZIP·전체 파일과 운영 자체 파일 105개 해시가 일치했다.

공개 다운로드 ZIP을 사용한 실제 42.21 전용 서버에서 패치 로드와 7개 도시·16곳 활성화를 확인했다. 각 위치의 실제 맵을 로드하고 운영의 `PZLinuxContractsSpawnZombieAt` 함수를 호출해 **16/16곳 표적 생성·이동 객체/좀비/월드 목록 등록·온라인 ID·계약 태그 PASS**, 실패 0건을 확인했다. 확인한 표적은 격리 월드에서만 제거했다. 서버는 `Shutdown handling finished`, 종료 코드 0으로 정상 종료했으며 운영 INI·SandboxVars·플레이어 DB·글로벌 데이터 해시가 유지됐다. 기존 다른 모드의 시작 경고가 있어 전체 모드 구성이 오류 없이 동작한다는 의미는 아니다.
