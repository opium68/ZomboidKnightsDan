# 2026-10-24 운영 설치본 배포

릴리스 후보: `0.1.0-20261024.1`. 현재 운영 자체 모드와 같은 파일을 참가자에게 배포한다. 공개 활성화와 배포 후 검증은 진행 중이다.

- 사냥 의뢰 후보를 멀드로우 Dixie Highway 한 곳에서 7개 도시 16곳으로 확대한다. 기존 의뢰와 현재 의뢰판은 유지하며, 새 의뢰판 생성부터 확대된 도시를 선택한다.
- 음악 학습 판정 확률에 10%포인트를 더한다. 곡 레벨 조건과 재학습 간격은 유지한다.
- 악기 11종의 학습·악보 읽기·디버그 학습 직후 곡 목록 저장을 보강하고, 연주 완료·중단 때 이미 알고 있던 곡을 보존한다. 이전에 잃은 곡을 자동으로 지급하지 않는다.
- 미 해병대 P19A의 네 좌석 하차점을 차체 바깥으로 보정한다. 다른 차량 변형은 변경하지 않는다.

검증: 설치된 PZLinux 원본 Lua를 실제 Kahlua에서 실행한 사냥 위치 16곳 선택·의뢰 생성 검사 통과. 16곳의 현재 맵 자산 존재 확인. 사냥 생성·복구 회귀 통과(월드 객체는 대역). 음악 11종 원본 학습·디버그·악보 읽기 및 목록 교체 회귀, 확률 보정 병행 검사 통과. P19A 네 좌석 네이티브 스크립트 병합 검사 통과.

서명 설치·복구, 공개 다운로드, 격리 서버 부팅 및 실제 표적 생성 검증 결과는 완료 후 추가한다. 실제 참가자의 수락·참수·보상 수령과 차량 하차 화면, 음악 재접속 후 목록 유지는 별도 게임 확인 항목이다.

기존 참가자는 게임을 종료하고 기존 `JOIN-SERVER.cmd`로 업데이트한다. 운영 서버는 정상 재시작해야 새 공유/서버 Lua를 읽는다. 이번 배포는 세이브나 진행 중인 의뢰를 초기화하지 않는다.
