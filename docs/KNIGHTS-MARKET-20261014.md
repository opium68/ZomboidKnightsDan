# 암시장 상품군 추첨·일반 구매 구성품 표시

사용자 확정: 수리킷·전투식량 필수 공급 제거. 모든 상품군은 서로 다른 상품 0~3종을 추첨한다. 전투식량도 0~3종, 수리용품도 없는 날이 가능하다. 의류 세트 하나를 상품 1종으로 센다. 재고 수량은 기존 가격별 재고 규칙을 유지한다.

상품군: 총기 / 근접무기 / 탄약·탄창 / 총기 부착물 / 의류 세트 / 가방 / 보조 장비 / 수리용품 / 전투식량 / 기타 식품 / 의료품 / 도구 / 기타 물자. 기존 후보의 첫 아이템 및 네이티브 아이템 종류를 기준으로 분류한다. 같은 아이템을 여러 상품으로 중복 추첨하지 않는다. 후보가 3종 미만인 상품군은 보유 후보 수까지만 등장한다.

게임 월드 경과 시간 24시간 구간마다 한 번 추첨하고 서버 전체가 목록·재고를 공유한다. 재입장·판매 후 갱신·재시작으로 재추첨하지 않는다. 상품군별 모두 0종인 경우도 유효하며 강제로 재입고하지 않는다. 기존 결제 주문은 보존한다. 변경 버전의 최초 암시장 접근 때 현재 목록은 새 정책으로 한 번 전환된다.

일반 물품 구매 채팅은 실제 선정된 아이템의 표시 이름과 수량을 결제 전에 보여준다. 같은 품목은 합산하며 번역 이름이 없으면 아이템 코드를 표시한다. 원본 모드 파일을 복제하거나 수정하지 않고 구매 UI의 개별 인스턴스에 표시만 추가한다. 가격·선정·결제·배송 데이터는 바꾸지 않는다. 차량 차종·인도 위치 표시는 유지한다. 일반 구매의 하루 고정 목록은 이번 변경에 포함되지 않는다.

상태: 구현 및 Kahlua 동작 검사 PASS. 실제 서버·운영 적용 결과는 아래 기록한다.

## 0.1.0-20261014.2 수정 적용

사용자 스크린샷으로 .1의 첫 일반 구매 화면에서 구성품 표시가 누락됨을 확인했다. 원인은 원본 onContractId가 loadingMessage를 지연 생성하는데 패치가 그 호출 전에 패널을 찾았기 때문이다. 원본 함수 호출 직후, 코루틴 첫 실행 전에 패널 후크를 연결하도록 수정했다. 이전 검사는 미리 생성된 패널을 가정해 이 경로를 놓쳤다.

운영 .1 파일에 새 회귀 검사를 실행하면 첫 패널 후크 검사에서 실패하고 .2 소스에서는 통과한다. 일반 물품 거절은 onMinimizeBack만 호출해 당일 상품군을 소진하지 않는다. 차량 거절은 기존 동작을 유지한다. 이미 소진된 상품군은 다음 갱신 때 돌아오며 구매 성공 기록을 일괄 되돌리지 않는다. 일반 구매의 하루 고정 품목은 아직 구현 전이다.

세트 가방 아이콘 Bag_DuffelBag를 기본 게임 아이콘 Duffelbag로 수정하고 분류를 Bag로 지정했다. 전체 25개 선언 및 생성기에 반영했다.

서명 릴리스 .2 생성, PS5.1 설치·복구·재실행 검사 PASS. 사용자의 다음 종료 때 적용 요청에 따라 서버/게임 종료를 확인하고 .2를 운영 적용했다. 백업: backups/owned-mods-before-0.1.0-20261014.2. 운영 자체 파일 68개 해시 일치. 공개 stable 채널 활성화 및 검증은 아래에 기록한다. 실제 멀티 구매 화면은 재확인 대기.
