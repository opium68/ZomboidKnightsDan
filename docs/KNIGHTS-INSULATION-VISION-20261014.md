# 보온성 완화·시야 모드

사용자 승인: 모드로 추가한 의류의 보온성을 J&G 수준으로 낮추고, 대기 중이던 Zombie Visibility Fix + Stair-O-Vision을 추가한다.

보온성 원본: config/knights-clothing-insulation.json. 설치된 의류 정의를 감사해 상한보다 높은 197개 ID를 지정했다. 부위별 상한은 헬멧 0.20, 방탄복 0.60, 팔·다리 보호대 0.15, 일반 상하의 0.30, 장갑 0.80, 신발 0.90이다. 이미 낮은 수치는 올리지 않는다. 기본 게임 아이템을 포함하지 않는다. 방어력·방풍성·방수성·무게·야간투시 기능은 변경하지 않는다.

스크립트 보온성은 부팅 때 한 번 수정한다. 저장된 기존 장비는 플레이어 생성/재접속 때 소지품을 한 번 확인하며, 착용 변경 이벤트 때 착용품만 확인한다. OnTick/OnPlayerUpdate/시간 간격 스캔은 추가하지 않는다. 보온성이 낮아져도 날씨·활동량·옷 겹침·방풍성으로 더울 수 있으며 더움·추움 무들 자체를 제거하지는 않는다.
