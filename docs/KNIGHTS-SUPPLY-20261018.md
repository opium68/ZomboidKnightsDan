# 2026-10-18 무기·탄약·계약 패치

릴리스: `0.1.0-20261018.4`. 구현과 실제 42.21 격리 엔진 검증 완료. 운영 자체 모드 99개 파일이 서명 패키지와 일치한다. 공개 배포는 아래 배포 기록을 따른다.

## 변경 내용

- Metro2033Armory를 활성 모드·Workshop 목록, 판매·보상 카탈로그 및 제작 제한 참조에서 제거한다. Metro 전용 58개 ID의 기존 물품은 무보상 삭제한다. 공용 바닐라·VFE 탄약은 보존한다. 기존 세이브의 클래스와 ID를 읽기 위한 자체 최소 호환 정의만 남기며, 원본 Metro 코드나 자산은 배포하지 않는다.
- 접속한 캐릭터의 인벤토리·장착품·가방과 로드되는 보관함·바닥·시체를 정리한다. 차량은 로드된 타일·탑승 플레이어 및 로드된 차량 Set 순회 경로에서 확인한다. 오프라인 캐릭터·미로드 지역은 다음 접속/로드 시 처리하므로 배포 시점에 저장 파일 전체를 일괄 편집하는 방식은 아니다. 저장된 주문에서 제거할 물품만 빼고, 이미 수령한 소포 표시와 다른 물품은 보존한다. 원본 구버전 배송 큐도 이관할 때 같은 정책을 적용한다.
- M60 두 형태와 100발 파우치는 일반 7.62×51mm(`Base.308Bullets`)를 사용한다. 기존 링크 탄은 1:1로 변환하고 빈 링크·링크 상자를 제거한다. 장전 수량은 보존한다. 링크 배출 콜백만 원본 VFE 진입점에서 제외하고 재장전 로직은 원본을 읽어 사용한다. 링크 제작·포장 레시피는 차단하며 기존 100발 결합 레시피는 비운다. 기존 링크 제작 금형은 보유품 삭제 대상에 포함하지 않는다.
- 일반 총기 71종을 총 1정·호환 탄창 4개·탄창 4개를 채울 실탄의 가방 세트로 판매한다. 내장 탄창식은 최대 장탄수의 2배 실탄을 넣는다. M60은 파우치 4개·400발이다. 구성품 생성 실패 시 불완전한 유료 세트를 지급하지 않는다.
- 큰 상자가 있는 일반 탄약 12종 중 5종을 중복 없이 추첨하고 탄종별 큰 상자 1~5개를 입고한다. 권총탄 일부/.22는 600발, .44 및 소총탄은 240발, 샷건은 300발이 큰 상자 1개다. 재고는 서버 공유이며 게임 달력 날짜가 바뀌는 자정에 갱신한다. 최초 적용 시 카탈로그 구조가 바뀌므로 기존 미결제 암시장 제안은 만료시키고 새 목록을 생성한다. 결제 완료 주문은 보존한다.
- 차량탄은 12.7×99mm·20×102mm 일반탄 중 매일 1종, 고폭탄은 25% 확률로 추가 입고한다. 일반탄은 100발, 고폭탄은 50발이 1팩이며 각 1~5팩을 입고한다.
- 운영 중인 탄창식 총기의 호환 탄창은 별도 고정 판매한다. 종류별 하루 8개 공유 재고이며 M60 파우치를 포함한다. 탄약 5종 추첨에 탄창을 섞지 않는다.
- 세트 이름에 탄종·탄 수량·탄창 종류·4개 구성을 표시하고, 탄창 단품에는 호환 총기를, 큰 상자·차량 팩에는 발수를 표시한다. 기본 가격은 기존 기준가를 우선 사용하며, 없는 품목은 총 15,000·탄창 1,500·실탄 1발 10의 초기 기준을 사용한다. 무기 세트는 구성품 가격을 합산한다. 차량 팩 기준가는 12.7mm 10,000·20mm 일반 20,000·고폭 15,000이다. 원본 기술·평판 거래 배율은 유지한다. 기존 단품의 판매 대금 수령을 위해 구매 입고에서 제외된 단품도 판매용 카탈로그에는 보존한다.
- 계약 금전 보상을 원본 5배로 올린다. 기존 미완료 3배 계약은 5배로 이관하고 새 제안·임무·처치 추가 보상에도 적용한다. 완료/취소 기록·기존 잔고·확정된 협동 지급 대기는 보존한다.
- 기존 건물 보호 추적에 탈출 최종 방어 웨이브를 연결한다. 유효한 생존 참여자를 추적하고 사망·오프라인 시 전환하며 단계 종료 시 강제 추적을 해제한다. 사냥 표적은 이동 불가·고정 대기 방식을 유지한다. 일반 좀비에는 적용하지 않는다.
- 배송 실패 이유와 부분 수령·복구 소포 수·남은 주문·미수령 수량을 한국어로 표시한다. 확인하지 못한 실패 원인은 추정하지 않는다. 기존 주문별 실패 격리·부분 배송 복구·중복 방지는 유지한다.
