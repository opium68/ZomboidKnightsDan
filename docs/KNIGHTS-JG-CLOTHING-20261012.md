## 판매와 생성 제한

기존 16개 세트와 신규 J&G 5개를 합쳐 21개 세트 가방을 판매한다. J&G 세트는 재킷·바지·장갑·전술화·헬멧·방탄복·어깨·팔꿈치·무릎 보호대 9종이다. 중복 착용 슬롯을 검사했다. 세트 가방의 생성 콜백에서 구성품을 전부 담고 텍스처 0을 고정한다. 콜백 중복 실행은 내용을 복제하지 않으며 구성품 생성 실패 시 새로 만든 구성품을 회수한다.

기존 개별 의복은 새 상품 후보에서 제거한다. 기존 결제 완료 단품 주문과 플레이어 소유품은 그대로 유지한다. J&G 마스크/가방은 신규 판매에 넣지 않는다. J&G 아이템 137개와 특수 좀비 의상 5개를 자연 생성에서 제거하고 제조 제작법 94개는 기존 서버 요구 기술 제한으로 차단한다. 실제 42.21 로더는 `enabled` 키를 인식하지 않으므로 신규 제작법에 해당 오버레이는 만들지 않는다.

새 위장복 세트의 기준가는 블랙 멀티캠과 같은 $105,000, 트라우마 대응은 승인된 $270,000이다. 기존 세트는 승인된 3배 가격을 유지한다. 개별 세트/색상을 동일 확률로 추첨하는 현행 방식은 유지하며, 상품군 우선 추첨·매일 고정 및 의류 슬롯 제한은 별도 미완료 항목이다.
