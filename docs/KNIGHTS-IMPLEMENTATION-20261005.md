운영 버전은 `0.1.0-20261005.5`다. 기존 `escape_test` 세이브를 백업하고 전체 구성을 반영했으며, Steam 활성 전용 서버의 정상 시작과 공개 배포 ZIP의 익명 다운로드·서명·SHA-256 검증을 확인했다. 서버는 실행 상태로 유지한다.

## 적용 내용

- Workshop 85개, Mod ID 93개. 추가 다운로드 23개이며 Dismantle Any Car는 활성 목록에서 제거하고 Vehicle Repair Overhaul + Vehicle Salvage Overhaul B42로 교체했다. Better Auto Mechanics는 유지한다.
- 자체 패치 3개: 기존 KnoxEscapeQuest v0.3.3, KnightsDanServerPatch v0.1.0, KnoxM60BulkLinks. M60은 기존 5발 연결과 같은 작업 시간에 탄·링크 각각 100개로 연결탄 100개를 만드는 별도 레시피를 추가했다.
- PZLinux는 개인 계좌를 유지한다. 근처 플레이어를 우클릭 메뉴로 초대하고 초대를 수락한 뒤 대표가 컴퓨터 의뢰를 수락한다. 수락 시 모두 온라인·10칸 이내여야 하며 이후 참여자는 고정된다. 진행도를 공유하고 등록 캐릭터마다 보상 전액을 한 번 지급한다. 오프라인 참여자의 미지급 보상은 다음 은행 동기화에서 정산하며 새 캐릭터는 이전 캐릭터 보상을 상속하지 않는다. 공동 구매·공용 계좌는 추가하지 않았다.
- 컴퓨터 노후화·수리 UI, 주식 진입·거래, 월드 누적 시간에 따른 물가 상승을 제거했다. 자동 로그인 연출, 전기, 신분증 해킹, ATM, 우편, 평판 및 기존 의뢰는 유지한다. 상품 난수 가격과 기술·평판 할인은 유지한다.
- 선정 장비·완성 전투식량·수리킷·차량을 상점에 연결했다. 등록 상품 791개(군장 색상 변형 포함), 차량 11종이다. M113은 의존성만 설치하고 구매 목록에는 넣지 않았다. 전투식량은 현실 영양 설정을 적용한 개별 식량 36종을 공급한다. 상점 갱신 때 수리킷 2종과 순환 식량 3종을 기본 재고로 추가한다.
- 선정 모드의 아이템·차량 자연 생성, 군장 좀비 의상, 시작 지급을 차단했다. 생성 레시피 161개 중 B42 craftRecipe 139개는 비활성화하고 기존 recipe 22개는 기술 요구 99로 제한했다. 수리·연마·장착·탄약 장전은 유지한다. 구형 Base.MRE 변환 경고를 없앴다.
- NVFramework 한 개만 사용한다. Nano Easy, KATTAJ1, Cerberus, Legendary 4개, Metro, M163, M998, KI5 스포츠카 3개, 특성 잡지, MRE, 총기 수리킷, Repair Any Weapons 기본 모듈을 활성화했다. Tactical Vision·Corvus·Dragonslayer·Guns of Marz는 추가하지 않았다.

## 배포

[최초 설치 런처 ZIP](https://github.com/opium68/ZomboidKnightsDan/releases/latest/download/KnightsDan-Launcher.zip)을 풀고 `JOIN-SERVER.cmd`를 실행한다. 이후 같은 파일을 실행하면 공개 운영 버전 목록을 확인하고 필요한 자체 패치를 자동으로 갱신한다. 원본 모드는 Steam Workshop으로 받는다. 비밀번호는 별도 전달한다.

- 운영 버전 목록: https://raw.githubusercontent.com/opium68/ZomboidKnightsDan/main/distribution/stable.json
- GitHub Pages는 `/docs`로 구성하며 같은 서명 목록을 `docs/distribution/stable.json`에 게시했다. 최초 활성화의 Pages 빌드 시간을 피하려고 런처는 Raw 주소를 사용한다.
- 공개키를 내장한 RSA 서명과 ZIP·개별 파일 SHA-256 검사, 경로·Mod ID 검사, 게임 실행 중 교체 차단, 전체 릴리스 백업·실패 복구를 구현했다. 이전 버전 제거 범위도 이전 서명 목록에서 확인한다. 개인 설정·세이브·다른 모드는 보존한다.
- 서명 비밀키는 운영자 계정 DPAPI로 보호한 로컬 파일이며 배포하지 않는다. 공개 저장소에는 자체 코드·공개 설정 참조만 올리고 Workshop 원본·세이브·계정 정보는 올리지 않았다.
- 가격은 `config/knights-reward-prices.json`의 초기 초안이다. MRE 350, 일반/고급 총기 수리킷 750/2,500, 군장 7,500, Nano 부위 20,000, 특성 잡지 30,000, 스포츠카 325,000, M998 350,000, M163 1,000,000을 기준으로 기존 할인·난수 보정이 적용된다. 실제 플레이 수입 측정 후 조정할 수 있다.

### 2026-10-17 배관 복구·디버그 로딩 수정

- 일반 접속의 admin에게 우클릭 최상위 `확장 배관 복구 (관리자)`를 추가했다. LGEP가 설치되어 있으면 배관 기능이 꺼져 있어도 표시한다. 확인창에서 승인하면 원본 LGEP `adminuninstall` 명령을 보내며, 서버의 기존 admin 검사를 그대로 거친다. 클라이언트에서 싱크대 플래그나 세이브를 직접 변경하지 않는다.
