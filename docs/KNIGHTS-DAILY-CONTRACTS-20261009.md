## 2026-10-14 건물 보호 추적 변경 (.7, 운영 적용)

건물 보호 계약에 표식이 붙은 좀비만 살아 있고 접속 중인 참여자를 계속 추적한다. 서버는 2초마다 로딩된 좀비 목록에서 해당 표식을 확인하고 가장 가까운 참여자를 지정한다(층 차이에는 거리 가중치). 새 계약은 고정된 캐릭터 참여 명단을 사용하며, 구형 개인 계약은 소유자/수락자와 현재 계약 ID가 일치해야 한다. 참여자가 사망하거나 접속을 종료하면 다른 참여자로 전환하고, 아무도 없으면 강제 추적을 해제한다. 처치 목표 달성 뒤에도 계약을 완료/취소하기 전까지 추적을 유지한다. 완료·취소·계약 기록 제거 시 강제 지정을 해제한다. 생성 수 50~199, 생성 위치, 목표 처치 수, 보상은 변경하지 않는다.

멀티 서버가 좀비 modData에 대상 온라인 ID와 캐릭터 키를 기록하고 대상 변경 때만 전송한다. 실제 이동은 해당 좀비를 제어하는 클라이언트가 담당하며 remote 복제본에는 명령하지 않는다. 서버 소유 좀비/싱글플레이는 서버 측에서 이동을 지시한다. 온라인 ID가 재사용되어도 캐릭터 키가 다르면 추적하지 않는다. 기존 계약의 로딩된 좀비에도 자동 적용한다.

클라이언트 재지정은 약 2초 간격, 추가 길찾기는 같은 대상에 최소 6초(이동 없음은 12초) 간격이며 125ms 구간당 최대 4회로 제한한다. 근접 공격 거리에서는 추가 경로를 요청하지 않고 엔진의 재탐색 지연을 유지한다. 일반 좀비에 modData를 새로 생성하지 않는다. 애니메이션 버퍼/트랙은 변경하지 않는다. 로딩되지 않은 청크의 좀비를 강제로 활성화하거나 벽/층간 길찾기 제한을 무시하지 않는다.
