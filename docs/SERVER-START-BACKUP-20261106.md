# 서버 시작 및 백업 보완 — 2026-11-06

## 정상 종료 확인 파일이 없는 경우

정상 종료 확인 파일이 없거나 체크포인트와 맞지 않을 때 지역 초기화뿐 아니라 서버 시작까지 중단하던 오류를 고쳤다. 이제 OfflineReset은 DEFERRED를 반환하고 기존 월드로 시작한다. 종료 표식을 임의로 만들거나 상태를 정상 종료로 위장하지 않는다. 올바른 정상 종료 표식이 있고 내부 생존자가 없는 다음 재시작에는 기존 범위 백업·CRC 검증 후 지역 초기화를 수행한다. 초기화 진행 중 표식, 잘못된 체크포인트 및 DB 오류 등 다른 보호 장치는 유지한다.

수정본은 실제 운영에 설치했다. 시작 전 캐릭터·차량·전역 자료·체크포인트·이미 적용된 과거 초기화 지시 6개 파일의 SHA-256이 같음을 확인했다. 실제 로그는 RCE_RESET=DEFERRED reason=missing-clean-stop preserve-world=true 및 SERVER STARTED를 기록했고 회차 4·기본 앰플 배치 9개를 유지했다. 기존 접속 설정으로 UDP 16261/16262에서 실행 중이다. 누락·불일치·손상된 종료 확인 파일의 경우 모든 fixture 월드 바이트가 유지되고, 올바른 종료 확인 파일에서는 기존의 정상 초기화가 작동하는 회귀 검사를 통과했다.

## 변경 파일만 다시 압축하는 독립형 전체 ZIP

scripts/backup-server.ps1은 이전 백업 ZIP을 복사하고 신규·변경 파일만 다시 압축하며 삭제된 파일은 새 ZIP에서 제거한다. 이전 ZIP은 수정하지 않는다. 생성한 새 ZIP 하나만으로 전체 복구할 수 있으며 증분 파일 체인을 요구하지 않는다. 모든 ZIP 항목의 CRC 검사, 파일 목록/크기 대조, 백업 중 원본 변경 검사 및 SHA-256은 유지한다.

파일 크기·UTC 정밀 수정 시각·생성 시각을 로컬 인덱스에 기록해 변경 여부를 판단한다. NTFS 정밀 수정 시각이 확인된 기존 ZIP은 CRC·해시 검증 후 기준 인덱스로 등록할 수 있다. 기존 ZIP에 생성 시각이 없는 항목은 수정 시각·크기를 비교하고, ZIP 작성 이후에 새로 생성된 파일은 다시 압축한다. 같은 시각을 의도적으로 보존하며 내용을 편집하는 특수 작업 후에는 ForceFull을 사용한다. 기준 ZIP/인덱스가 없거나 손상됐으면 전체 백업으로 자동 전환한다. 인덱스는 성능 최적화용이며 복구에 필요하지 않다.

기존 설정·계정 DB·월드 전체에 더해 계정 DB의 WAL/저널과 RCE 체크포인트·초기화 지시·초기 설치 표식·정상 종료 확인 파일도 포함한다. 실행 중인 해당 서버의 백업은 막는다. 임시 압축은 기존처럼 LOCALAPPDATA 아래에서 수행하고 완료한 파일만 backups로 옮긴다. 한글 ZIP 이름은 UTF-8로 저장한다. 7-Zip이 없으면 전체 ZIP 방식으로 생성하며 압축 해제한 내용과 원본의 SHA-256까지 대조한다.

## 실제 적용과 검증 범위

- 사용자가 만든 escape_test-20261106-160045.zip은 SHA-256 79B6C8576EB3F578C19DFB8CAAA13465711B54FF6ABE8160E33FDD723BEA88F2와 전체 CRC를 확인한 뒤 그대로 기준 백업으로 등록했다. 파일 244,741개·디렉터리 1,708개이며 원본 ZIP 및 실행 중인 월드는 수정하지 않았다.
- 기존 ZIP에서 가져온 수정 시각은 실제 파일 표본 100개 모두 정확히 일치했다. 실행 중인 월드를 읽기 전용으로 파일 정보만 비교했을 때 244,744개 파일 중 신규/변경 361개, 삭제 0개였고 비교 시간은 약 0.98초였다. 실제 백업 총 시간은 서버 정상 종료 후 다음 백업에서 측정한다.
- 1.5만 파일 fixture에서 PS7 전체 약 3.32초 → 변경분 약 1.63초, 변경 없음 약 0.66초였다. PS5.1에서도 약 3.11초 → 1.72초, 변경 없음 약 0.97초를 기록했다. 실제 운영의 170초와 직접 비교할 수 있는 동일 데이터 벤치마크는 아니다.
- 모든 복구 파일 바이트, 같은 크기의 초 미만 수정, 과거 시각의 교체 파일, 신규 파일, 삭제 파일/폴더, 한글 파일명, 이전 ZIP 불변, WAL/RCE 포함, 기준 ZIP 해시 불일치 시 전체 백업 전환을 검사했다. 실제 운영 월드에 시험용 압축·복구·변경을 수행하지 않았다.

## 사용법

기존 HOST-SETUP-AND-RUN.cmd를 그대로 사용한다. 현재 실행 중인 서버를 다시 시작할 필요는 없다. 다음 정상 종료 후 실행부터 등록된 기준 백업을 사용한다.

항상 전체 재압축하려면 프로젝트에서 아래를 실행한다.

```powershell
./scripts/backup-server.ps1 -ServerName escape_test -ForceFull
```

이 변경은 서버 운영 파일에만 해당한다. 클라이언트 서명 배포는 0.1.0-20261106.5를 유지하며 플레이어 모드와 홍보 PDF는 바꾸지 않는다.
