# 2026-10-18 패치 목록

대상: Project Zomboid 42.21 서버. 게임 모드 최신 적용 버전은 `0.1.0-20261018.3`이다. 백업 개선은 호스트 실행 스크립트 변경이다.

## 적용 완료

### 백업

- 원클릭 업데이트 과정에서 전체 백업이 두 번 실행되던 중복을 제거했다. 업데이트 전에 완료한 백업을 같은 실행의 설정 배포에서 재사용한다.
- 일반 서버 실행·최초 설치·설정 배포 단독 실행의 백업은 유지한다.
- 기존 백업 파일을 삭제한 변경은 아니다. 백업 한 번에 필요한 압축·검증 시간은 여전히 발생한다.

### Jumbo Tree Indoor Fix 제거

- 42.21 기본 기능과 겹치는 `JumboTreeIndoorFix`를 서버 활성 목록과 플레이어 배포 목록에서 제거했다.
- 월드·캐릭터 초기화와 Steam 구독 파일 삭제는 필요 없다.
- 42.21 자체 나무 렌더링 오류의 해결을 보장하는 변경은 아니다.

### PZLinux 임무

- 사냥·방어 임무의 좀비 생성 호출을 42.21에서 지원하는 방식으로 수정했다.
- 월드에 정상 등록되지 않은 사냥 표적을 계속 재사용하던 경로를 보완했다. 잘못된 표적은 재검사하고 기존 임무의 복구 경로로 재시도한다.
- 표적 근처의 일반 좀비를 사냥 목표로 오인하지 않도록 계약 정보와 서버 식별자를 확인한다. 이전 임무의 식별자를 새 임무에 재사용하지 않는다.
- 방어 임무의 연속 생성은 사냥 표적의 재시도 간격 제한을 받지 않도록 했다.

### PZLinux 배송·구매 물품 수령

- 암시장·요청 물품 수령 후 상태 동기화에서 발생하던 오류를 수정했다.
- 잘못된 주문 하나 때문에 뒤의 정상 주문까지 수령하지 못하던 문제를 수정했다.
- 실패한 유료 주문과 부분 배송 기록을 보존해 재시도할 수 있도록 했다.
- 구버전 주문의 이관이 실패해도 완료로 처리해 원본 주문을 잃던 문제를 수정했다. 이관 진행 기록을 보존해 재시도 시 중복 생성도 방지한다.

## 확인 및 접속 안내

- 백업 실행 경로 검사, 원본 PZLinux Lua 기반 회귀 검사, 실제 42.21 격리 서버 부팅·정상 종료, 서명 업데이트·복구 및 운영 모드 파일 대조를 통과했다.
- 실제 멀티플레이에서 사냥 표적 표시와 물품 수령 조작은 확인 대기다.
- 플레이어는 게임을 완전히 종료한 뒤 기존 `JOIN-SERVER.cmd`로 업데이트한다. 개인 전역 모드로 Jumbo Tree를 켰다면 해당 모드도 비활성화한다.

## 논의 중 · 미적용

- M60의 링크 탄 사용 방식과 발사 시 링크 배출 방식 변경은 아직 적용하지 않았다.
- 일반 탄약의 게임 표시 이름은 **7.62x51mm 탄약**, 내부 ID는 `Base.308Bullets`다. 이번 확인으로 탄약 이름이나 드롭 설정을 변경하지 않았다.
